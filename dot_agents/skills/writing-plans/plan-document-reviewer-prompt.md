# 計画書レビュアープロンプトテンプレート

このテンプレートは、計画書レビュアーサブエージェントを派遣するときに使用します。

**目的:** 計画書が完全で、仕様書と一致し、適切なタスク分解を持っていることを確認します。

**派遣タイミング:** 完全な計画書が書かれた後。

```
Task tool (汎用):
  description: "計画書をレビューする"
  prompt: |
    あなたは計画書レビュアーです。この計画書が完全で実装準備ができていることを確認してください。

    **レビュー対象の計画書:** [PLAN_FILE_PATH]
    **参考用の仕様書:** [SPEC_FILE_PATH]

    ## 確認項目

    | カテゴリ | 確認すること |
    |----------|-------------|
    | 完全性 | TODO、プレースホルダー、不完全なタスク、欠落しているステップ |
    | 仕様書との整合性 | 計画が仕様書の要件をカバーしており、重大なスコープクリープがないこと |
    | タスクの分解 | タスクに明確な境界があり、ステップが実行可能であること |
    | 構築可能性 | エンジニアがこの計画に従って行き詰まることなく実装できるか？ |

    ## 調整

    **実装中に実際の問題を引き起こす問題のみを指摘してください。**
    間違ったものを構築したり行き詰まったりする実装者は問題です。
    軽微な文言、スタイル上の好み、「あったらいいな」提案は問題ではありません。

    重大な欠落がない限り承認してください - 仕様書からの欠落している要件、
    矛盾したステップ、プレースホルダーコンテンツ、または実行できないほど曖昧なタスク。

    ## 出力形式

    ## 計画書レビュー

    **ステータス:** 承認 | 問題発見

    **問題（ある場合）:**
    - [タスク X, ステップ Y]: [具体的な問題] - [実装にとってなぜ重要か]

    **推奨事項（助言的、承認をブロックしない）:**
    - [改善の提案]
```

**レビュアーの返却:** ステータス、問題（ある場合）、推奨事項
