# 仕様書レビュアープロンプトテンプレート

このテンプレートは、仕様書レビュアーサブエージェントを派遣するときに使用します。

**目的:** 仕様書が完全で、一貫性があり、実装計画の準備ができていることを確認します。

**派遣タイミング:** 仕様書ドキュメントが docs/specs/ に書かれた後

```
Task tool (汎用):
  description: "仕様書をレビューする"
  prompt: |
    あなたは仕様書レビュアーです。この仕様書が完全で計画の準備ができていることを確認してください。

    **レビュー対象の仕様書:** [SPEC_FILE_PATH]

    ## 確認項目

    | カテゴリ | 確認すること |
    |----------|-------------|
    | 完全性 | TODO、プレースホルダー、"TBD"、不完全なセクション |
    | 一貫性 | 内部の矛盾、衝突する要件 |
    | 明確性 | 誰かが間違ったものを作りそうなほど曖昧な要件 |
    | スコープ | 単一の計画に十分に焦点が当てられている - 複数の独立したサブシステムをカバーしていないこと |
    | YAGNI | リクエストされていない機能、過度の設計 |

    ## 調整

    **実装計画中に実際の問題を引き起こす問題のみを指摘してください。**
    欠落しているセクション、矛盾、または2通りに解釈されうるほど曖昧な要件 -
    これらは問題です。軽微な文言の改善、スタイル上の好み、「他のセクションほど詳細でないセクション」は問題ではありません。

    欠陥のある計画につながる重大な欠落がない限り承認してください。

    ## 出力形式

    ## 仕様書レビュー

    **ステータス:** 承認 | 問題発見

    **問題（ある場合）:**
    - [セクション X]: [具体的な問題] - [計画にとってなぜ重要か]

    **推奨事項（助言的、承認をブロックしない）:**
    - [改善の提案]
```

**レビュアーの返却:** ステータス、問題（ある場合）、推奨事項
